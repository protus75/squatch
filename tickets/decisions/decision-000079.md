No action. The message assumes the driver has no Outcome for an over-bound render. The merged code already has one. `Stages._call` (squatch/stages.py:1022-1036) catches `RenderRefused` around `Driver.run`. It logs the terminal with `outcome="premise_failed"` and returns a zero-cost `StageResult(outcome="premise_failed")` carrying one `render_refused` Finding with the refusal's paved road. `test_an_over_bound_render_is_a_premise_failed_terminal_before_any_call` (tests/test_stages.py:958-968) pins this: no model request, a `premise_failed` delivery, the over-bound message plus the 'split the ticket' road, and nothing lifted. Diagnosis is skipped for `premise_failed` (squatch/diagnose.py:132-134), which meets section 8's 'no diagnosis call'. The park and release follow the ordinary premise path in drain.py:358-362. This is the second of the message's two options, already built. Adding a new `Outcome` value now would create a second terminal path for a park the code already serves through `premise_failed`, and the no-dual-path and anti-bloat laws rule that out. What remains is plan wording, the same kind of gap decisions -000072 and -000074 handled. Section 8 (SQUATCH_PLAN.md:1118) says 'a named stage terminal' 'like `budget_exceeded`' and says 'no cap draw', but never names the Outcome. Also, runner.py:442-444 draws `premise_bounce` on every `premise_failed` terminal, this one included, so 'no cap draw' holds only for the retry, diagnosis and infra caps. No rendered ticket or decision covers the Outcome for an over-bound render. The open config-*, gates-*, journal-*, seams-*, lockfile-* and effects-* tickets are unrelated, so a tombstone would be wrong. Reopen if a plan regeneration adds a separate over-bound Outcome or reads 'no cap draw' as excluding `premise_bounce`, or if the operator treats the wording as a plan defect. The fix then is to reword SQUATCH_PLAN.md:1118 so it says the refusal terminals as `premise_failed` with a `render_refused` finding, and to state whether it draws `premise_bounce` (as built) or is exempt (a code change in the same diff).
