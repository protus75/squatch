No ticket. The leak this message predicts is closed in the merged code. All ticket-plane writes go through `lift_ticket_files` (squatch/stages.py:1155). Its outbox walk drops any path whose first component is `attempts` (stages.py:1172-1173), so an agent cannot put a `run.md` under `attempts/<n>/` through a nested outbox path. The `files=` mapping that the harvest passes in (squatch/harvest.py:96-100 builds `attempts/<run_seq>/run.md`) is redacted by file name, not by root-relative path: `if Path(rel).name == RUN_RECORD: data = redact(...)` (stages.py:1194-1196). The terminal harvest calls this lift with the configured redactor (squatch/runner.py:415-418). So a configured secret in the worktree `run.md` is redacted before `attempts/<n>/run.md` is committed. Copying from the canonical `tickets/<stem>/run.md` instead would add a second source path for the same bytes and fix nothing. The acceptance pin the message wants is narrow. shakeout-stages' planted-secret member (eval/shakeout/stages_group.py:286-313) checks every committed `tickets/<stem>/` path for the secret, but it runs on an approved (ok) terminal, so no `attempts/` directory is created. tests/test_harvest.py:92-105 checks only the Box copy. A dedicated non-ok pin would therefore test a code path that already redacts. Under D10 it has no incident behind it: the message gives no evidence and comes from `bootstrap-ingest`. A tombstone does not fit cleanly. spine-harvest owns the lift, but no rendered item covers this regression pin by name. Reopen if a harvested `attempts/<n>/run.md` on main is ever found to contain a configured secret value, if a regeneration of spine-harvest drops the by-name redaction at stages.py:1195 or the `attempts` exclusion at :1173, or if the battery's planted-secret member is extended to a non-ok terminal, in which case the attempts check comes at no extra cost.

Evidence: squatch/stages.py:1172-1176 (outbox walk excludes `attempts/`; root `run.md` redacted), squatch/stages.py:1194-1196 (`files=` entries named `run.md` redacted at any depth), squatch/harvest.py:96-100 (harvest builds `attempts/<run_seq>/run.md` into `files=`), squatch/runner.py:415-418 (terminal harvest lifts with the configured redactor), eval/shakeout/stages_group.py:286-313 (planted-secret member covers committed ticket-plane paths on an ok terminal only). Separate observation, not filed: outbox files at any depth other than root `run.md` and other than `attempts/`, such as `sub/run.md` or files with names not in KNOWN_ARTIFACTS, are lifted without passing through the redactor (stages.py:1175-1181). That gap is outside this message's `attempts/` claim and should go in its own box message if pursued.
