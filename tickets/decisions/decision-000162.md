No ticket for now. The mechanism the message describes is real, but no incident has been cited, and the only full fix is a plan-semantics change that needs the operator. On the drain path, `_precheck` (squatch/merge.py:296-304) tests for an empty diff against the delivered `slip.base..slip.branch`. That diff is non-empty, so the branch passes. `_rebase` (:336-348) then rebases onto main. If main already carries the same change, the rebased head equals main. `_regate` (:366-396) builds the candidate with `base` = main and runs `Verification` with `allow_empty` true only for a qualifying OUTBOX lift or a seed lift. `Verification.check` (squatch/stages.py:362-366) therefore emits 'the branch carries no committed diff' with the road 'commit the work on the branch', and the admission ends `gate_failed`. That road is wrong for this case. The case still has a working release path: `gate_failed` draws `retry` and the stem stays re-runnable on its branch. The next Implement finds the work already on base and can answer `already_satisfied`, which `Verification` accepts with an empty diff and `_precheck` settles with `reviewed=None` and `commit: null`. So it costs one retry, but nothing is stranded. The message proposes two fixes. (1) Settling at admission as 'already integrated': section 5 makes `already_satisfied` an Implement/Check proof about the base. An `implemented` verdict settling at merge with no commit is a new settlement path, so the plan would have to name it first, and that is the operator's call. (2) Naming the re-run road: this is a narrow paved-road wording fix. It is the cheaper option, but it is unearned under D10 while no run has hit the case. The message cites no evidence, and Phases 2-6 merged without it occurring. No rendered work or decision covers it, so a tombstone would be wrong: outbox-only-admission covers only lifted-artifact empty diffs, and verification-attribution covers only base-red commands. Otherwise, a narrow ticket can make the regate's empty-after-rebase finding name the re-run/`already_satisfied` road.
