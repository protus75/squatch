No ticket. The message gets the delimiter wrong and is half out of date. The engine delimiter is `<<<squatch:` (DATA_MARKER, squatch/specs.py:37). The string `[squatch-data:` is the quoted escape the engine substitutes for it, not something the renderer refuses. The diff half is already solved. The review stage quotes the diff before rendering it (squatch/stages.py:1012, `diff.replace(DATA_MARKER, "[squatch-data:")`), and tests/test_stages.py:1001 `test_review_visibly_quotes_engine_delimiters_without_changing_the_diff` pins this. Diagnose (squatch/diagnose.py:96-107, :163), the prior-attempts re-entry (stages.py:794), author (author.py:361) and triage (triage.py:361) quote the same way, so a ticket that touches squatch/specs.py or specs/*.md can be reviewed. Merged work shows it happening: requisition-review-call added specs/requisition_review.md and merged through review. The Context half is real, but it is the plan's intended design and not a defect. specs.py:35-36 says a delimiter in injected content is a render refusal and that 'this is why section 13 refuses `specs/*.md` as Context'. That refusal has a paved road. Requisition review turns a delimiter refusal into a mechanical snag whose road is 'remove the delimiter-carrying file from Context' (squatch/requisition.py:241-242, tests/test_requisition.py:140-153). The seeded-phase tests also check that every cited Context path is free of the delimiter. Seeds that touch the renderer or a spec already work this way: the file sits in the fence and is not cited as Context, and the implementer reads it from the worktree. A per-render nonce delimiter or a Context escape would be new spec that weakens a deliberate break-out refusal. No incident has earned it (`evidence: None`), and every phase through Phase 6 has merged under the current rule. No rendered work or decision covers how delimiter-carrying files are handled, so a tombstone would be wrong. Reopen if a ticket's goal cannot be met unless a delimiter-carrying file is supplied as Context, if a review or diagnose render is refused over the delimiter in a diff, or if the operator changes the section 13 Context exclusion.
