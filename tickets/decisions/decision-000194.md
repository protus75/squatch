No ticket. The asymmetry is real, but no part of the system reads it, and it already fits the plan's meaning for these events. `Drain._drain` (squatch/drain.py:224-225) journals `timer_armed` with kind `drain_max_runtime` once per invocation. It journals `timer_fired` only on the ceiling-halt paths (:246, :255), which are the only places the ceiling trips. The section 6 event table (SQUATCH_PLAN.md:988-989) defines `timer_armed` as 'a deadline is scheduled' and `timer_fired` as 'a deadline elapses'. A drain that reaches quiescence before admission is blocked never trips the deadline, so having an arm with no fire is the correct record and not a lost event. The module docstring (drain.py:24-27) already says that only the trip is journaled as 'the armed timer firing'. The record therefore has no missing explanation that a docstring line would supply. No reader depends on the pair matching. The restart-safe `Timers` fold in squatch/timers.py:21-37 works only on `kind=deadline` records and leaves the drain ceiling records to their current owner (restart-timers run.md). Nothing re-arms or reaps an unfired ceiling. The audit and the retros only count these events. The other fix in the message, skipping the arm when the first scan is empty, would add an ordering branch: the arm happens before the loop's first `_scan`. The record would then depend on queue contents for no behavioural gain. D10 and the simplest-thing rule both argue against it, and the message calls the asymmetry harmless and gives no evidence. A tombstone does not fit. restart-timers covers `kind=deadline` timers, not the drain ceiling's arm/fire pairing, and no rendered open ticket or decision covers this. Reopen if any fold, audit invariant, or restart path starts treating an unfired `drain_max_runtime` arm as pending or orphaned, or if the plan adds a rule that every `timer_armed` must be closed by a `timer_fired` or a cancel event.

Evidence: squatch/drain.py:224-225 arms once per invocation, before the first scan. squatch/drain.py:246,255 fire only on the ceiling halt, and quiescence returns at :244 without firing. SQUATCH_PLAN.md:988-989 defines fired as 'a deadline elapses'. squatch/drain.py:24-27 docstring already says that only the trip is journaled as the firing. squatch/timers.py:21-37 folds only `kind=deadline` and ignores drain ceiling records.
