No ticket: the operator has to fix this in the plan. The message is right that the plan has a gap. SQUATCH_PLAN.md:380-382 requires every fixture's expected.json to record the author identity as `(provider, model, tier)` and requires that author to differ from the REVIEW route, at minimum by tier. It never says what `tier` means for an author that did not go through the routing table. Bootstrap fixtures are written that way, because the AUTHOR route is placeholder-blocked until the operator sets model ids. The merged code has filled the gap with its own convention. All committed fixtures record `{"provider": "claude", "model": "claude-sonnet-5", "tier": "medium"}`, the routing default tier. `check_author_diversity` (eval/harness.py:363-380) refuses a fixture only when `(a.provider, a.model, a.tier)` equals `(reviewer.provider, reviewer.model, tier)` at the exercised tier. So for a non-routed author the recorded tier label can decide whether the diversity check passes, even though no route ever chose that tier. A regeneration from :379-382 could pick a different convention, such as a null tier, the reviewer's tier, or a requirement that provider/model differ, and the committed fixtures could then fail the check or pass it for the wrong reason. Nothing is broken today because the harness and the fixtures agree. Under the plan-is-the-seed rule the fix goes in plan prose, and engine tickets do not write plan prose. Decisions -000072, -000074, -000079, -000080, -000091, -000092, -000096, -000097, -000102 and -000103 went to the operator for the same reason, so an authored ticket would have nothing it is allowed to change. No rendered work or decision covers the tier of a non-routed fixture author. decision-000103 is about prompt 2's fixture file list (ticket.md), not author identity. go-grade-machinery and go-grade-run cover the GO-grade harness. The open config-*, gates-*, journal-*, seams-*, lockfile-*, effects-* and startup-* tickets are unrelated. A tombstone would therefore be wrong. The other is a different rule: a non-routed author must differ from the reviewer in (provider, model), because a tier label it never ran under proves no diversity.
