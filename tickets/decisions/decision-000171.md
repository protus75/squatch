No ticket. The fact in the message is correct, but its location is out of date, and the change it suggests would make things less robust. `EngineLog.__init__` (squatch/enginelog.py:28) runs `self.path.parent.mkdir(parents=True, exist_ok=True)`. Under `_locked`'s `go()` (squatch/__main__.py:705), which is now the shared composition behind the run, drain, serve and similar verbs, the runner's `EngineLog` is built before `Runner.session` takes the lock. So the state dir can be created before the lock is acquired. That is harmless, as the message itself says. `Lockfile.acquire` also creates the same directory with `exist_ok=True` (squatch/lockfile.py:66). Both calls are idempotent and create only an empty directory. Nothing inside it is written, read or used for a dispatch decision before the flock is held, so a second process gets nothing out of the early mkdir. Taking the mkdir out of `EngineLog` would make its first `event` write depend on some earlier caller having created the directory. `EngineLog` is built at six sites (decision-000167), and several of them, such as `_triage_pass`, stages, merge and serve, get the state dir from callers that order things differently. A missing directory would then show up as an `OSError` on a diagnostic write. That is less robust than what happens today, and it would add an ordering dependency for no observable gain. The plan has no rule that only the lock acquirer may create the state dir. The message cites no evidence, and Phases 2-6 merged on this layout, so under D10 the change is speculative. No tombstone fits: decision-000167 covers sharing `EngineLog` instances, not when the directory is created, and none of the open tickets touch state-dir creation. Reopen if the plan assigns state-dir creation to the lock acquirer, or if any engine file under the state dir is found to have been written before the lock was acquired.

Evidence: squatch/enginelog.py:28 (mkdir in EngineLog.__init__); squatch/__main__.py:705-706 (EngineLog built in _locked's go() before the session takes the lock); squatch/lockfile.py:66 (Lockfile.acquire does the same idempotent mkdir); squatch/__main__.py:545 (_triage_pass builds EngineLog inside the session, after the lock); decision-000167 (EngineLog construction sites and the declined composition-root refactor).
