No ticket. The behavior described is real, but it is what the plan specifies, and nothing has shown it to cause harm. `Drain._refuse_cycles` (squatch/drain.py:338-346) runs on every `_drain` pass right after `_scan` and `_provider_holds`. When `cycle_through` finds a cycle anywhere in the committed plane's `depends` graph, it raises `Refusal`, and that stops the whole invocation. The paved road says to break the cycle in one of the named tickets' `## Depends on` and re-run. Section 18 of SQUATCH_PLAN.md (lines 589-591) requires exactly this: 'Fail closed: an empty ready set is reported, not an error; a depends cycle is refused with a paved road'. Changing it to a per-member `Held` entry would mean editing the plan first (the plan is the seed), and that needs a real case behind it. There is none. The message itself says intake already refuses cycles before commit, so the only way a cycle reaches the committed plane is a hand commit that skips the sanctioned intake path. CLAUDE.md section B already requires ticket files to go through that path. The message gives no evidence (evidence: None), and Phases 2-6 merged with this refusal in place without any recorded stall. Under D10 a partial-hold path is speculative. It would also add a second way cycles are handled (refused at intake, held at drain), which the no-dual-path and simplest-thing rules weigh against. Refusing the whole drain also stops everything until a human fixes the plane. That is not a hold without a release, because the refusal names its release. A tombstone does not fit: no rendered open ticket, merged Goal line or decision covers cycle handling in the drain. drain-draft-await-confirm and drain-parked-detail only change report lines, and decision-000185 covers how much the scan costs, not cycle disposition.

Evidence: squatch/drain.py:233 calls `_refuse_cycles(plane)` on every pass. squatch/drain.py:338-346 raises `Refusal` naming the cycle and the `## Depends on` paved road. SQUATCH_PLAN.md:589-591 says 'a depends cycle is refused with a paved road'. The message has no evidence field, and it says the path is reachable only by hand-committed tickets that bypass intake's pre-commit cycle refusal. Reopen if a journaled drain refusal for a committed-plane cycle is ever recorded, if a machine path (seed lift, Author, Rework split) is found that can commit a cycle past intake, or if the serve scheduler must decide cycle disposition and the plan adds a per-member hold rule.
